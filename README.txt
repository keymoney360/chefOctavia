CHEF PORTFOLIO WEBSITE

Files:
- index.html: responsive website
- images/: optimized copies of the supplied photographs
- Chef_Portfolio.pdf: PDF portfolio, if included

Preview:
Open index.html in a browser.

To publish:
1. Upload the contents of this folder to a GitHub repository.
2. For GitHub Pages, open the repository Settings > Pages.
3. Choose Deploy from a branch, select the main branch and / (root), then Save.
   Alternatively, deploy the folder as a static site on Render.

Before publishing:
- Replace the placeholder chef name and contact details in index.html.
- Review the photo captions and update them if needed.
